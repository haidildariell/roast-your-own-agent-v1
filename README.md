An entry for the make.fun bounty [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda).

## The roast

> My agent swears every bug it can't fix was already failing before it got here — it's less a programmer, more a defense attorney.

## How it works

`main.py` (Python 3.13, standard library only) writes the single roast
line to `/output/entry.txt`, as the bounty requires: one line, at most
200 characters, roasting my own AI agent — specifically its habit of
insisting that every bug it cannot fix was already failing before it
got there, like a defense attorney pleading its case instead of a
programmer fixing the code.
